# Complementary CP/M Utilities for the CCP

I thought that it may be worthwhile if I were to provide a subset of my [highly curated set of CP/M 2.2 and CP/M 3 command line utilities](</Distribution/Additional CPM Utilities>). These commands add to, replace or augment those that would normally be used along with daily usage of a CP/M CCP. In addition, many of them are referenced in my *Aliases.cmd* file. I've included their related documentation and source code, if and when available.

| CP/M Command | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:------------ |:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3dir.com     | A very flexible and amazing directory lister by John Elliott. It only works with CP/M 3. It shows the exact file sizes. Refer to help files and source in the ZIP file                                                                                                                                                                                                                                                                                                |
| 3show.com    | Shows free disk space (mapped over to the UNIX-style 'df' command in alias.cmd). It only works with CP/M3. Refer to the .doc file.                                                                                                                                                                                                                                                                                                                                    |
| D23.com      | After evaluating "almost all" CP/M directory listing programs I keep coming back to D-23 as my go-to preferred solution. Type "d23 //" to get help or d23.hlp. I've modified offset 0x58 to be "3" for 3 columns rather than 4 and offset 0x0B from 0x18 (24) to 0x1e (30) for the # of lines.                                                                                                                                                                        |
| L2-45.com    | A complex directory lister by Richard Collett, June 1987. Includes support for listing all or single user areas. From the MBUG disk images on the "retro" site of the Microbee Repository. Show help via "l2-45 ::". Recompiled for 64x30 output.                                                                                                                                                                                                                     |
| QL.com       | Highly recommended as the best over-all file viewer.  It combines some of the best features of the popular CP/M, ZCPR3, and MS-DOS utilities LUX, LT, VLU, and LIST62 with unique features of its own, including hex display mode and a unique, fast access, file reference by number system. This version  extends the numbered  file access to  the LBR directory and adds "batch" viewing/extractions. LBR extractions, more. Recompiled for Exidy Sorcerer 30x64. |
| RSXdir.com   | List all CPM3 RSX's in memory.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| RSXmap.com   | List all memory used by CPM3 RSX's in memory.                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Rename37.com | The "go to" rename program developed by many contributors. Version 3.7. Handles CP/M, DOS, interactive and wild-card renaming.                                                                                                                                                                                                                                                                                                                                        |
| Sstat.com    | An extended disk status program.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| TPAsize.com  | List memory size of TPA.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Xdir.com     | X-Directory III v2 by Richard Conn. Set for 64 columns. Recompiled for 3 columns x 30 lines, sorted horizontally, no attr display and grouped by filename/ext. Type "xdir //" for the list of options. Note: this was my preferred directory listing program over D23.com but it becomes very slow (ie. 43 seconds) if there are hundreds of files spanning multiple user areas.                                                                                      |
| ZSW.com      | Z80 Turbo Sweep file manipulation program v1.4 (Aug 1987). Based on NSW v.207 by Dave Rand (July 17 1984). From the MBUG disk images on the "retro" site of the Microbee Repository.                                                                                                                                                                                                                                                                                  |
